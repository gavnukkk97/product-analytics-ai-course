## 1. Общий учебный продукт

Все уроки этой папки крутятся вокруг одного продукта курса:

| Поле | Значение |
|---|---|
| **Название** | **Ритм** |
| **Что это** | B2C-приложение привычек с freemium и подпиской Pro |
| **Работа пользователя** | «Хочу удерживать 1–3 ежедневных ритуала, не бросая через неделю» |
| **Основной сценарий** | онбординг → первая привычка → чек-ин → серия (streak) → paywall → подписка |
| **Монетизация** | бесплатный базовый слой; Pro — 299 ₽/мес или 1 990 ₽/год |
| **Почему этот продукт** | короткая воронка, явный ретеншн, юнит-экономика подписки, измеримые экраны |

Детали сценария, черновые метрики и события уточняются по модулям; **стенд синтетики** — [`../stand/`](../stand/) (Postgres + Metabase, CSV-семпл, генератор, ключ A/B для преподавателя).

## 2. Формат одного урока

Каждый файл `mX.Y-*.md` содержит:

1. **Шапка** — ID модуля, неделя/проход, опоры, аудитория, длительность ориентир.
2. **Цели** — что умеет аналитик и что умеет продакт после урока (одна строка на роль + общий минимум).
3. **Контекст Ритма** — зачем этот модуль именно на нашем продукте; при необходимости — к какой вехе P1–P4 относится практика.
4. **Теория коротко** — модель и правила, не энциклопедия.
5. **Разобранный пример** — один сквозной кейс на Ритме.
6. **Практика** — ядро (оба) + расширение «руки» + расширение «решение».
7. **Критерии приёмки** — чек-лист, по которому можно сдать.
8. **Линия AI** — где со-пилот уместен и что проверяем руками.
9. **Дальше читать** — ссылки на наши inventory-docs / публичные опоры из них.
10. **Визуалы** — минимум 2 обучающих диаграммы (Mermaid в тексте и/или SVG в `visuals/`).

Имена файлов: `m0-1-contour.md`, `m0-2-ai-in-contour.md`, `m1-1-problem-market.md`.

## 3. Две аудитории в одном треке

Не разводим потоки. Одно задание:

| Слой | Кто делает | Что сдаёт |
|---|---|---|
| **Ядро** | все | артефакт, без которого нельзя идти дальше |
| **«Руки»** | аналитик (и сильные продакты) | расчёт / схема / проверка цифры |
| **«Решение»** | продакт (и сильные аналитики) | постановка, дыра в выводе, деньги, защита |

Студент сдаёт ядро + хотя бы одно расширение.

## 4. Визуальные договорённости

- Диаграмма **учит**: контур, дерево метрик, воронка, таксономия событий, разрыв контура. Не декор.
- Предпочитаем **Mermaid** (в тексте урока) и **SVG** (в `visuals/`, ссылка из урока). ASCII — только как запасной дубль.
- Один визуал — одна идея. Подпись: что смотреть и какой вывод сделать.
- Цвета в SVG сдержанные, без «фиолетового неона»; акцент — на поток и разрывы.
- Именование: `visuals/m0-1-contour.svg`, `visuals/m1-1-metric-tree.svg`.

## 5. Как в уроке появляется AI

В каждом уроке блок **«Линия AI»** отвечает на три вопроса:

1. Где AI ускоряет (код, черновик вариантов, формулировки).
2. Что AI **не** выбирает за вас (метрика, гранулярность, решение).
3. Какая **проверка** обязательна до того, как цифра или текст попадут в сдачу.

Формулировка курса: *AI — соавтор кода и черновика; вывод и ответственность — ваши.*
